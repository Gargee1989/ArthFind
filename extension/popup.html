How to get your API key
NVIDIA NIM Recommended Visit
  1. 1Go to developer.nvidia.com/nim and click Sign Up
  2. 2Create a free account with your email
  3. 3From the dashboard, click Generate API Key
  4. 4Copy the key starting with nvapi-... and paste it here
Google Gemini Visit
  1. 1Go to aistudio.google.com and sign in with your Google account
  2. 2Click Get API Key in the left sidebar
  3. 3Click Create API key and select a project
  4. 4Copy the key starting with AIza... and paste it here
OpenAI Visit
  1. 1Go to platform.openai.com and click Sign up
  2. 2Verify your email and set up billing (required for API access)
  3. 3Go to API Keys in the left menu and click Create new secret key
  4. 4Copy the key starting with sk-... — it won't be shown again
